# 题号与大题识别（结构层，2026-10-25）

本文记录 `src/exam_structure.py` 如何从物理行恢复「大题 / 题号 / 小问」，以及为什么
不能靠一条正则解决。背景：新增的 10–12 页教师版/解析版语料（`data/eval/`）用行首
「（1）（2）」当题号，并把小问也写成「（1）」；旧实现只认 `12.` 这种行首数字，
直接导致 eval01/eval04 重建出 0 题、eval02 误报缺选项。

## 判定顺序

每页按 `reading_order`（栏感知）取行，逐行依次判断：

1. **跳过**：页码/页眉页脚、纯数字碎片、空行（既有规则不变）。
2. **参考答案标记**：整行只由 `参考答案` / `答案与解析` / `答案及评分标准` / `评分标准`
   组成（`ANSWER_KEY_RE`）→ 从其后的行开始进入 `appendix`，不再建题。
   注意：解析版把 `【参考答案】` 写在题内、页脚也含「参考答案…第 N 页共 M 页」，
   这两种都**不算**标记（有页码的是页脚，已跳过；带【】的不匹配）。
3. **大题标题**：`一、选择题：共10小题…` 这类行建 section，并解析「共 N 小题」写
   `section.declared_questions`（`DECLARED_RE`，夹 1–60）。
   - 若**同一标签 + 同一 declared 数**的标题第二次出现 → 判定为文末答案区开始，
     置 `appendix`，不建 section（否则答案区重复的 一/二/三 会变成 3 个空大题）。
4. **题号**：
   - 先试 `QUESTION_RE = r"^\s*(\d{1,3})\s*[.、．)）](?!\d)\s*(?=\S)"`（`12.` 风格），
     保留既有的“异常大数剥前缀 / 同号剥前缀”噪声处理。
   - 失败再试 `PAREN_QUESTION_RE = r"^\s*[（(]\s*(\d{1,3})\s*[)）]\s*(?=\S)"`，
     且必须通过 `_paren_number_follows()`：**数字大于当前最后一题**（最多允许 +5 的
     漏题跳跃）才算新题号；没有已识别题时接受 1–30。小问在每个题内从 1 重数，
     因此「（1）」出现在第 15 题内部时必然小于 15，按小问处理。
5. **小问**：`(1)`/`（1）` 且未被第 4 步认作题号 → 当前题的小问。
6. **选项**：`OPTION_RE = r"(?:[（(]\s*([A-D])\s*[)）]|(?<![A-Za-z0-9])([A-D])\s*[.．])\s*"`
   允许标签前面紧贴汉字（`（A）充分（B）必要` 同一行两个选项）。
7. **续行**：其余行按当前指针追加到题干 / 选项 / 小问。

## 小标题被吞时的分节

OCR 会整行漏掉小标题（实测 eval01/eval04 的「二、填空题」）。当前大题已写
`declared_questions` 且题数收满后，再出现题号 → 开一个
`{"id": "sec-NN", "label": "", "title": "", "inferred": true,
  "reason": "section_heading_missing"}` 的推断大题：

- 不猜标题文字，也不继承上一个选择题大题的「必须有 A–D」要求；
- `build_quality()` 为它报 **warning** `section_heading_missing`（含题数），不报 error；
- 这样既不会把填空/解答题误判成缺选项，也不隐藏“这里的小标题是推断的”。

## 不可恢复的情况（如实失败）

- OCR 丢行首数字：eval05 的 `.若复数z 3-i,`（丢了 `2`）→ 只认出 1/3/8/10/11，
  `question_number_gap` + `section_empty` 是真错误，规则救不回。
- 整页文本被打散：eval03 第 1 页 → 只 7 题、缺 1–11 与 13，`question_number_gap` 如实报。
- 公式被识别坏：eval04 `\(\underline{\text{\(\sqrt{30}\)}}\)` 嵌套定界符不平衡 →
  `formula_structure_broken` error（公式门的职责，不改判为结构问题）。

**禁止**为让某套卷过门放宽正则、把 `(n)` 一律当题号、或写单卷特例：那会把小问变成题号，
在 23 套历年卷上造成回归。
