# S6 规格：真实试卷批量验收（可复核，不挑样本）

## 目标

S6 不引入新的识别模型，而是回答一个工程问题：**同一套命令，换 20 套真实试卷，
还能不能稳定通过？** 它把“某张卷看起来还行”变成可重跑的证据：

1. 输入既可以是 PDF（重新跑版式流水线），也可以是已生成的 `*.layout.json`
   （`--reuse`，用于回归，不重新 OCR）；
2. 每套卷都落 `layout/exam/quality` 三件套和原始日志；
3. 统一汇总 `acceptance.json` / `acceptance.md`：页数、行数、题数、覆盖率、
   选项完整率、公式结构通过率、表格填充率、每页人工动作数、质量门状态；
4. 任一硬门失败退出码为 1，不允许“大部分通过就算过”。

## 用法

```powershell
# PDF 全跑（需要 OCR 服务）
python tools\run_exam_acceptance.py data\exams\corpus\*.pdf --out-dir out\acceptance\2026-01

# 只重算结构/质量，不重新 OCR
python tools\run_exam_acceptance.py --reuse out\exams\*.layout.json
```

默认阈值：

| 指标 | 阈值 | 说明 |
|---|---|---|
| 页面覆盖率 | ≥ 99% | 墨迹被行/图/表覆盖的比例；防“整栏漏识别” |
| 公式结构通过率 | ≥ 95% | 定界符/括号/环境可解析，**不是**公式内容全对 |
| 表格填充率 | ≥ 90% | 需填单元格非空比例，**不是**表格 F1 |
| 人工动作/页 | ≤ 1.0 | `quality.repair.plan` 里的 `manual` 数 |

选项完整性是硬门：文字选择题必须达到 `4 × 题数` 个非空选项；缺少选项直接失败。
纯图形选项（如“函数图象大致为”）没有文字选项，记为 `option_mode=graphical` 并
在 `quality` 里单独 warning，不按 4 个空文字项判失败。
`quality.status == fail`、`check_layout_json`/`check_render`/`check_exam_json`
非零同样直接失败。

## 语料

`data/exams/corpus/` 放 15 份不同年份/地区的高考数学真题，`data/exams/` 另有
6 份 A3 横向卷（其中 2 份与 corpus 重复），再加 1 份区模拟卷，去重后合计 20 套；覆盖：

- 2 栏、3 栏、A3 横向、A4 纵向；
- 有文字层、扫描件；
- 纯文字卷、带统计表/分布列/几何图的卷；
- 不同大题命名（单选题/多选题/填空题/解答题）。

验收报告必须保留每套卷的完整日志，失败项要能定位到页/行/题号，而不是只给一个
“识别失败”。

## 已修正的真实缺陷（验收驱动）

| 现象 | 根因 | 修正 |
|---|---|---|
| 2023 北京第 2 页只剩右栏 | 栏缝候选按“两侧字数”打分，短栏页把栏内 8–13px 空隙选成中缝 | 改为**优先最宽空白**；同宽再比两侧字数 |
| 2024 北京少 Q20/Q21，题号重复 | 跨栏重复行合并时 `native_left` 被置空，原生文字行被吞 | 合并时保留较短一侧的 `native_left` |
| 2025 上海只有 4 题 | 栏缝识别阈值 5% 漏掉 395pt 窄栏 | 最小空白宽度降为页面宽的 0.25% |
| 2024 全国文/2023 上海少选项 | OCR 把 `(D)` 吞进题干 | 题干尾部补回 `(D)`，并做选项完整性门 |
| 2025 天津/2024 北京少选项 | `A.` 形式未识别 | 选项正则同时接受 `A.` / `A．` / `(A)` |
| 2024 全国文/2025 上海表格空 | 统计表填充分母把合并表头空格算成缺失 | 只统计需要填内容的格 |
| 题干与 `(A)`…`(D)` 同行时选项丢失 | 题号分支把整行当续行，未再拆选项 | 题号行内先保留 `(A)` 前题干，再逐项拆选项 |
| 2023 北京/2025 上海多出 B、C 假选项 | LaTeX `\(B\)`/`B)` 被选项正则当成选项 | 选项只接受 `(A)` / `（A）` / `A.` / `A．`，拒绝数学括号 |
| 2024 全国理/文“图象大致为”缺 4 个文字选项 | 四个小图排成 2×2，第二行离题号超过 80pt 成无主图 | 相邻图面板向上/下传播归属；纯图形选项记 `option_mode=graphical` |
| 2024 新高考 2 多出一个假 B | OCR 把 `B. 则 ()` 碎片单独成行 | 同题重复选项标签用后出现的完整项覆盖，不累加 |
| 2023 新高考 2 渲染“插图压正文” | 两个图的裁片各自过窄，漏掉跨图坐标轴标签 | 同一栏相邻图先并集再裁片 |
| 2024 新高考 2 题号跳到 68 | OCR 幻觉数字前缀 | 首题 >30 或跳号 >5 时去掉数字前缀当续行 |

这些修正全部是**数据驱动**的：先有 20 套语料里的失败样本，再改判据，避免为单张卷
写特例。

## 非目标

- 不保证 20 套全部 `quality=pass`；允许 `warn`，但 `error` 必须修；
- 不把“覆盖率 100%”等同于“内容全对”；OCR 错字、公式语义错误仍需人工/上层模型；
- 不把表格填充率说成表格 F1，也不把公式结构通过率说成公式识别准确率；
- 不在每次 `run_all_checks.py` 里跑 20 套 OCR（太慢），验收报告单独执行。

## 验收

1. `python tools/run_exam_acceptance.py ...` 产出 `acceptance.json` 和
   `acceptance.md`，20 套全部硬门通过；
2. 3 套从未参与调参的新卷单独跑一遍，作为最终用户验收；
3. `tools/test_exam_structure.py` 13 项、`tools/smoke_pipelines.py` ≥115 通过；
4. `tools/run_all_checks.py` 21/21；
5. 文档同步 `AGENTS.md`、`ocr_json_app/README.md`、`tools/README.md`。
